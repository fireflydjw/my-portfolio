# My Portfolio

个人主页项目 - 使用 HTML、CSS 和 JavaScript 构建的响应式个人作品集网站。

## 项目结构

```
my-portfolio/
├── index.html       # 主页面
├── css/
│   └── style.css    # 样式文件
├── js/
│   └── main.js      # 交互脚本
└── README.md        # 项目说明（本文件）
```

## 功能

- 响应式设计，适配桌面和移动端
- 固定导航栏，平滑滚动
- 英雄区（Hero Section）展示个人简介
- 项目展示卡片
- 联系信息区

## 技术栈

- HTML5
- CSS3 (Flexbox + Grid)
- Vanilla JavaScript

## 本地运行

直接在浏览器中打开 `index.html` 即可预览。
